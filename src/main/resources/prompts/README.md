# FAQ 프롬프트 입력 위치

승지님이 테스트 중인 프롬프트 본문은 이 작업에서 작성하지 않았습니다.
`faq-system.txt`, `faq-user.txt`는 의도적으로 비워 두었습니다.
두 파일이 준비되지 않은 상태에서는 LLM을 호출하지 않고 채팅에 준비 중 응답을 반환합니다.

## 적용 방법

1. `faq-system.txt`에 확정된 시스템 지침을 UTF-8로 작성합니다.
2. `faq-user.txt`에 확정된 사용자 메시지 템플릿을 UTF-8로 작성합니다.
3. 사용자 템플릿에는 `{{question}}`과 `{{faqs}}`를 모두 포함합니다.

| 자리표시자 | 들어가는 값 |
|---|---|
| `{{question}}` | 사용자가 입력한 원래 질문 |
| `{{faqs}}` | 검색된 FAQ 목록의 ID·질문·답변 |

자리표시자는 대소문자와 공백까지 위 표와 같아야 합니다. 두 입력을 어느 위치에 넣을지,
어떤 지침과 출력 형식을 사용할지는 프롬프트 담당자가 결정합니다.
실제 사용자 질문과 FAQ는 참고 데이터이며, 시스템 지침으로 승격하지 않습니다.

기본 리소스를 수정하면 실행 환경에 반영한 뒤 확인하세요. 실행 JAR을 사용한다면 다시 빌드하고 실행해야 합니다.
외부 파일을 사용하려면 Spring 설정 `prompt.faq.system-location`, `prompt.faq.user-location`에
`file:` 리소스 경로를 지정할 수 있습니다. 별도 설정이 없으면 위 클래스패스 파일을 읽습니다.

검색은 현재 ChatService에서 수행합니다. 가장 높은 점수 하나로 기존 0.75 기준을 판정하며,
이를 통과하면 검색된 전체 목록(최대 3개)을 전달합니다. 모든 FAQ가 0.75 이상이라는 뜻은 아닙니다.
유사도 기준이나 프롬프트의 사실 정확도를 이번 연결 테스트에서 검증한 것은 아닙니다.
